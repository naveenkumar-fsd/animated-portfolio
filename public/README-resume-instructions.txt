RESUME PDF — SETUP REQUIRED
===========================

This portfolio does NOT include a resume. The "Download Resume" buttons point to:

    /resume.pdf

To make them work:

1. Export your own resume as a PDF.
2. Rename it to  resume.pdf
3. Copy it into this folder (public/), next to this text file.
4. Restart `npm run dev` if it is running, then click "Download Resume" to verify.

Want a different file name? Put the file here with any name, then change
`resumeUrl` and `resumeFileName` in  src/data/portfolio.ts

Until the PDF exists, the buttons show "Resume unavailable" instead of a broken download.
You can delete this text file before publishing.
